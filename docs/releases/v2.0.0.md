### 使い方と移行 / Usage and migration

```text
docx-revision-analyzer chart report.docx
docx-revision-analyzer flow report.docx
docx-revision-analyzer score report.docx
docx-revision-analyzer snapshot archive/ report.docx
docx-revision-analyzer versions report.docx
docx-revision-analyzer --help
```

Windows では `docx-revision-analyzer.exe` を使います。macOS / Linux では `./docx-revision-analyzer` として実行します。 / Use `docx-revision-analyzer.exe` on Windows, or `./docx-revision-analyzer` on macOS/Linux.

**破壊的変更:** `docx-revision-chart` などの個別コマンドは、上記のサブコマンド方式へ置き換わります。旧名の実行ファイル・別名リンクは配布しません。オプション・既存 YAML 設定ファイル名・解析 JSON の `tool` 識別子と出力形式は維持しています。 / **Breaking change:** replace the separate command names with the subcommands above. No alias executables or alias links are included. Existing options, YAML filenames, analysis JSON `tool` identifiers and output formats are preserved.

Windows で `.exe` に文書を直接ドロップしても、サブコマンドを選べません。画面から操作したい場合はデスクトップアプリを利用してください。 / Dropping a document directly onto the Windows CLI `.exe` does not select a subcommand; use the desktop app for a graphical drag-and-drop interface.

### 注意 / Notes

- 配布物は Developer ID / Authenticode による署名・公証をしていません。macOS / Windows が初回実行時に警告する場合があります。 / These builds are not Developer ID / Authenticode signed or notarized; macOS or Windows may warn on first launch.
- macOS Apple Silicon 用の chart / flow ドロップレットも別添しています。どちらも統合 CLI を同梱します。 / Separate chart/flow droplets for Apple Silicon include the unified CLI.
- この公開は GitHub Releases のバイナリ配布です。npm パッケージの公開は別途行います。 / This release distributes standalone binaries on GitHub Releases; npm publication is separate.
